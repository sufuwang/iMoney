# iMoney

基于 React + Ant Design 的本地个人记账应用，移动端优先（iPhone 安全区适配、底部导航、底部抽屉），纯前端运行于浏览器。

## 功能

- **明细**：按日 / 月 / 年查看收支，分类结构、金额榜单、卡片式流水与关键词搜索。
- **统计**：收支走势、分类动态、构成比例、周期均值分析，支持自定义区间与图例筛选。
- **健康**：财务健康指数与四维评分（储蓄能力、收入稳定、支出分散、记账习惯）、储蓄率趋势、本月支出结构。
- **投资**：在「记一笔」抽屉切换到「资产」模式，按月和币种记录主动基金、纳指、标普的金额（自动按汇率换算为人民币汇总）；投资页查看资产走势、最新配置占比、月度环比与累计收益。
- 页面右下角的设置悬浮按钮提供多币种汇率管理、JSON 备份导入导出（含资产记录）和清空记录。
- 记账弹窗支持常用备注快捷输入；数据保存在 `localStorage`，首次启动载入 `src/data/seed.json` 示例数据。

## 本地运行

```bash
npm install
npm run dev
```

浏览器访问 http://localhost:3000 。

## 校验

```bash
npm run lint
npm run build
```
